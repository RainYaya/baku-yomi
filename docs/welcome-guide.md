# 第一次打开时，先记住这几件事

这不是一个必须先把所有配置都填完，才能开始用的工具。
你可以先导入、先读、先练，再慢慢补齐译文、AI 和 TTS。

## 导入什么样的书

- 最理想的是经过“沉浸式翻译”浏览器插件处理过的双语 EPUB。
- 这类书一般会保留日文原文和对应中文，所以导入后体验最好。
- 现在也支持单语小说 EPUB；如果书里没有中文，导入后中文位会留空，不会影响阅读和练习。

> 如果你想得到最完整的双语阅读体验，优先选择由沉浸式翻译生成的双语 EPUB。

## 阅读时最重要的操作

- 用 `j / k` 在句子之间移动。移动只会改变选中位置，不会自动打开练习。
- 选中一句后，按 `P` 打开句内练习卡，按 `E` 看讲解，按 `Shift + P` 进入整页练习桌。
- `gi` 跳到输入框，`r` 朗读当前句，`?` 随时查看全部快捷键。
- `Esc` 逐层退回：练习桌 → 练习卡 → 选中 → 阅读。

> 用鼠标也一样：点句子只会选中，练习、讲解和练习桌都在句子下方的按钮里。

## 两级练习：卡片和练习桌

- 句内练习卡贴在句子下方，适合快速补一句译文、顺手看一眼分析。
- 练习桌是一整页的工作台：左边原文，中间书写，右边反馈，适合慢慢打磨。
- 两级共用同一份译文草稿和分析结果，随时切换都不会丢。
- 讲解和练习在同一张卡的两个标签里，不用来回关面板。

> 单语书也能用：从空白译文开始，一步一步把中文补出来。

## 主题和快捷键

- 两套主题：纸页（浅色）和夜读（深色），在顶部右侧切换。
- 主题没有快捷键，避免和阅读页里的 `P`（打开练习卡）冲突。
- 阅读页的快捷键以 `?` 打开的列表为准。

> 主题只改变纸面的颜色，不改变任何内容的位置。
